# Provenance and ownership

This repository was extracted from `arch/`, `maps/`, `editor/`, and the
content-collection tools in
[`atrinik/atrinik`](https://github.com/atrinik/atrinik) at source commit
`f00d892c4`. Its filtered Git history retains changes that touched those paths.

Extraction does not relicense the content. Directory-local attribution and
license files remain authoritative and must move with the assets they cover.
The Atrinik maintainers own content review, collection tooling, digest
generation, and immutable semantic-version releases.
